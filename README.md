# Gnanha Creative

Tu es un expert en design UX/UI, développement front-end, branding, SEO et expérience utilisateur. Crée un site web complet, moderne, premium, responsive et très bien structuré pour une créatrice de site web nommé Gnanha W. Objectif :

- Créer un site vitrine complet et esthétique, adapté à un public professionnel.

- Donner une image premium, moderne, crédible et performante.

- Le site doit être prêt à être utilisé en production, avec un bon niveau de détail visuel et une navigation fluide.



Technologies recommandées :

- Next.js

- TypeScript

- Tailwind CSS

- Framer Motion (ou animations légères)

- React Icons / Lucide React

- SEO optimisé

- Design responsive mobile-first

- Accessibilité web (ARIA, contrastes, navigation clavier)

3. Section services

  - Titre

  - Description

4. Section "À propos"

5. Section chiffres / statistiques

- Exemples :

  - +250 projets livrés

6. Section portfolio / réalisations

7. Section témoignages

8. Section tarifs

- 3 offres :

  - Essentiel

  - Nom

  - Avantages

9. Section FAQ

- 5 à 8 questions fréquentes

10. Formulaire de contact

- Champs :

  - Nom

11. Footer
